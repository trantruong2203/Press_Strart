## 2025-05-15 - [Form Accessibility]
**Learning:** Authentication forms (Login/Signup) often lack `autoComplete` attributes, preventing password managers from correctly identifying fields. In this app, adding these attributes provides a significant UX boost with minimal code changes.
**Action:** Always check authentication and user-profile forms for standard `autoComplete` attributes (`email`, `current-password`, `new-password`, `username`, `name`).
