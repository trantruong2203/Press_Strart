## 2025-05-15 - Improving Browser Autofill with autoComplete
**Learning:** Modern browsers and password managers rely heavily on `autoComplete` attributes to provide a seamless login/signup experience. Missing these attributes forces users to manual type or copy-paste, increasing friction.
**Action:** Ensure all `TextField` components in authentication forms have appropriate `autoComplete` values (`email`, `current-password`, `new-password`, `name`).
